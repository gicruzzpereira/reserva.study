# Reserva Study

Projeto Plataforma Web de estudos para o ensino médio. Professor Marcelo - Aula 11.

## Atualizações do banco de dados

Para atualizar uma instalação existente, execute os arquivos `.sql` correspondentes
da pasta `database/atualizacoes/` no banco `reservastudy`. A atualização
`2026-11-11_acessos_e_notas.sql` habilita os perfis de professor e suporte e cria
a tabela de notas manuais (escala de 0 a 1000). Após a atualização, um administrador
cria as contas da equipe em **Usuários**; o login é feito pela tela habitual.
